## 环境搭建步骤
**1.下载系统镜像iso文件**
[Ubuntu‑22.04‑LTS Server 清华源](https://mirrors.tuna.tsinghua.edu.cn/ubuntu-releases/22.04/ubuntu-22.04.5-live-server-amd64.iso)


**2.创建虚拟机**
在VMware中创建四台虚拟机
| 命名 | 最低内存 | CPU | 硬盘 | 系统 | 网卡 |
|:----:|:----:|:----:|:----:|:----:|:----:|
| Manager | 4G | 2核 | 40G | Ubuntu | Host-Only |
| Target-A | 2G | 1核 | 20G | Ubuntu | Host-Only |
| Target-B | 2G | 1核 | 20G | Ubuntu | Host-Only |
| Target-C | 2G | 1核 | 20G | Ubuntu | Host-Only | 

安装方式选 Ubuntu Server
网络配置时：
1. 光标移到网卡名字（一般是 `ens33`），按回车
2. 选中 `Edit IPv4`，回车
3. 把 `Automatic(DHCP)` →改成 **Manual**，回车
4. 进入静态 IP 填写表单

- Subnet：`192.168.5.0/24`
- Address：`192.168.5.10` (managers最后一位是10，三个靶机11、12、13)
- Gateway：`192.168.5.1`
- Name servers：`223.5.5.5,114.114.114.114`
- Search domains：**留空，什么都不填**

填完向下移动光标到 `Save`，回车保存。
然后选最下面的 `Done`，进入下一步
不要重复进入IPv4配置界面查看，后两项表单会丢失
