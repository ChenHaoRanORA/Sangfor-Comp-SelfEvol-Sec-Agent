# 开发计划

> 顶层计划总览。详细架构见 [系统架构.md](./系统架构.md)，分阶段落地任务与完成定义（DoD）见 [开发指南.md](./开发指南.md)，数据集说明见 [../data](../data)。

### 项目概念
一个基于知识图谱与分层记忆系统的**自进化网络安全智能体**，以大语言模型为核心算力与决策中枢，融合本地网安专业知识图谱（Kùzu，ATT&CK 起步）、动态攻防模式经验与全维度审计数据，构建“**规则底座-模式认知-数据溯源**”三级联动的安全决策体系。

- **双类规则**：人工规则仅人工增删改（支持自然语言辅助编写）；衍生规则由系统自动动态增删改、可人工修改；每条规则统计**生效次数**。
- **分层记忆**：“历史片段 → 可疑模式 → 规则”，衍生规则可逐层溯源到模式与片段证据。
- **分级自主行动**：A0 通知 / A1 只读 / A2 受限 / A3 处置（必须人工确认 HITL）。
- **数据入口统一**：所有告警经**一个网络通讯接口（Ingress）**接收；现期用本地两数据集**离线训练**并初步构建衍生规则分层记忆，后期接入 VMware 靶场在线测试。
- 实现：规则引擎与大模型（LangGraph 工作流）双驱动，覆盖 自动化感知 → 智能研判 → 实时预警 → 闭环处置 → 经验迭代，解决传统设备规则固化、泛化弱、误报漏报高、无自进化能力等痛点，面向大规模服务器集群场景。

### 开发阶段
| # | 阶段 | 阶段要点 | 目标（详见开发指南） |
|---|---|---|---|
| 一 | 搭建环境 | conda `scssa`（langgraph/openai/fastapi/kuzu/chromadb…）；`.env` 配置；VMware 实验室（Manager + Target-A/B/C）与 Wazuh；Node/Vue3 前端 | 环境可跑通 + 大屏 Mock 首页 |
| 二 | 数据接入与数据集构建（离线） | **统一 Ingress**（HTTP Webhook，预留 Syslog/WS）；清洗归一化 linux-APT / llm-soc → 统一 `Alert`；回放器经 Ingress 投递 | 回放 1000 条零崩溃 |
| 三 | Agent 核心能力开发 | 双规则池规则引擎（生效计数）；LangGraph 处置流；LLMClient（研判/模式归纳/规则编译/NL 规则助手）；Kùzu 图谱导入 ATT&CK | llm-soc 178 条跑通研判闭环 |
| 四 | 多层记忆与自进化（离线训练） | 历史片段（SQLite+Chroma）→ 可疑模式（LLM+图谱）→ 衍生规则自动 CRUD；溯源入 Kùzu；**以两数据集离线跑批产出初始衍生规则分层记忆基线** | 衍生规则可分层检索/溯源 |
| 五 | 前端与闭环测试 | Vue3 监控大屏 + 后台（监测状态 / 告警历史 / 规则管理含生效次数与 NL 创建 / A3 审批）；A0–A3 动作；离线评测（178 基准）与消融 | 完整离线 Demo 可演示 |
| 六（后期） | 在线接入与靶场测试 | Wazuh 告警转发同一 Ingress；在线三级联动运行；在线自进化与回滚演练 | 离线/在线仅切换数据源无缝运行 |

### 技术选型
| 层 | 选型 |
|---|---|
| 虚拟化/SIEM | VMware Workstation；Wazuh（Manager + Target-A/B/C） |
| LLM 编排 | LangGraph（工作流/Agent，checkpoint + HITL）；openai 客户端（结构化输出，OpenAI 兼容端点） |
| 后端/接口 | FastAPI（REST + WebSocket + Ingress Webhook） |
| 前端 | Vue3 + Element Plus + ECharts（监控大屏 + 后台，演示）；Streamlit（仅内部调试） |
| 存储 | SQLite（规则/片段/动作/审计）+ Chroma（向量）+ Kùzu（专业知识图谱与溯源，networkx 导出/原型） |
| 知识库 | 本地网安专业知识图谱：ATT&CK 企业版（STIX）起步，后续扩展 CVE/CAPEC/CWE/KEV |

### 数据与运行模式
- **统一网络通讯接口 Ingress**：`POST /api/v1/ingest`（Webhook 为主，预留 Syslog/TCP、WebSocket），幂等去重与限速。
- **离线（现期默认）**：回放器把本地两数据集按时间压缩投递 Ingress，用于功能联调、离线训练与构建初始衍生规则分层记忆、离线评测。
  - [linux-apt-dataset-2024](https://www.kaggle.com/datasets/yacinenaoui/linux-apt-dataset-2024) —— Wazuh/APT Linux 审计流（模拟数据主体）
  - [LLM-SOC-Alert-Triage](https://github.com/c0deing/llm-soc-alert-triage) —— 多源攻击告警带标签基准（研判评测）
- **在线（后期）**：VMware 靶场 Wazuh 告警转发到同一 Ingress，验证在线自进化闭环。
